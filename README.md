# Telco Customer Churn Analysis

This project was developed for the Fundamentals of Data Science course.

The objective is to clean and explore a telecommunications customer churn dataset using Python. The analysis includes:

- Data cleaning and preprocessing
- Missing value handling
- Duplicate detection
- Data type validation
- Categorical consistency checks
- Exploratory data analysis (EDA)
- Univariate and multivariate visualizations

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

Dataset source:  
https://www.kaggle.com/datasets/blastchar/telco-customer-churn
